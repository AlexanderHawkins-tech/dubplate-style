# DUBPLATE-STYLE

Free in-browser visualiser for musicians. Upload your artwork and track, position it on a dubplate-style vinyl sticker, set the RPM and clip length (15 s–2 min), then export a spinning MP4 in vertical 9:16, square 1:1 or Instagram 4:5. No uploads, no sign-up — everything runs in your browser.

Live site: https://alexanderhawkins-tech.github.io/dubplate-style/
